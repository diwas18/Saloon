# Sunshine Salon Management System

A web-based salon management system designed to simplify service booking and business operations.

## Features

* Online service booking system (no login required)
* Admin dashboard to manage bookings and customers
* Simple and user-friendly interface
* Responsive design for mobile and desktop users

## Technologies Used

* Laravel (PHP Framework)
* MySQL Database
* JavaScript
* HTML/CSS

## Purpose

This project was developed to help small salon businesses manage customer bookings efficiently and reduce manual workload.
